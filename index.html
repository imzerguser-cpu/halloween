귀신 소재: 확인 전

③ 시작

전체 화면으로 학생 화면을 엽니다. 교사 모드로 돌아오려면 제목(🎃 할로윈 탐험대)을 빠르게 5번 누르세요.

무서움 강도 설정

출발할 때 학생들이 고른 답(너무 무서워요 / 조금 / 하나도 안 무서워요)에 따라 귀신과 소리를 다르게 합니다. 저장하면 구글 시트에 기록되고 모든 태블릿이 1분 안에 따릅니다.

이야기 고치기

출발할 때 나오는 이야기와 장소별 괴담을 무서움 단계마다 고칠 수 있습니다. 저장하면 구글 시트에 기록되고 모든 태블릿이 1분 안에 따릅니다.

조별 귀신 등장 장소

귀신은 조마다 딱 한 장소에서 나옵니다. 장소는 시트 설정의 "귀신시드"로 정해지며, 모든 태블릿이 같은 결과를 냅니다. 제외학년 학생이 있는 조와 귀신제외조는 나오지 않습니다. 다시 섞으려면 시트의 귀신시드 값을 바꾸고 모든 태블릿에서 "불러오기"를 하세요.

사진함 (이 태블릿)

빈 배경 촬영 (귀신 소재 만들기 1단계)

태블릿을 행사 때와 똑같이 고정한 뒤, 사람이 없는 상태로 찍으세요. 사진은 드라이브 "빈배경" 폴더(연결된 경우)와 이 기기 다운로드 폴더에 저장됩니다. 그 사진을 이미지 생성 AI에 올려 귀신을 그려 넣은 뒤 ghost-maker.html 로 귀신 소재를 만듭니다.

귀신 합성 시험

이 장소의 귀신을 무조건 넣어서 한 장 찍어 봅니다. 사진함에 저장되지 않습니다.

화면 귀신 미리보기

학생이 찍을 때처럼 카메라를 켜고, 촬영 버튼을 누르면 5초 카운트다운 중 귀신이 화면에 1초쯤 비쳤다 사라집니다. 조 배정과 관계없이 무조건 나오고, 사진은 저장하지 않습니다.

카메라 (이 태블릿)

빈 배경을 찍을 때와 행사 때 같은 카메라·같은 조명이어야 수정이 잘 됩니다.

나레이션 목소리 (이 태블릿)

이야기를 읽어 줄 목소리를 고르세요. 태블릿에 깔린 한국어 음성(구글·삼성)만 보입니다. 더 자연스러운 목소리가 필요하면 태블릿 설정 → 일반 → 텍스트 음성 변환에서 음성 데이터를 받으세요.

📥 Google 음성 엔진 받기·업데이트 ⚙ 음성 데이터 설치 화면 열기
  1. "Google 음성 엔진 받기"로 Google 음성 서비스를 설치·업데이트합니다.
  2. "음성 데이터 설치 화면 열기"(안 열리면 태블릿 설정 → 일반 → 텍스트 음성 변환 → 기본 엔진 Google → ⚙ → 음성 데이터 설치)에서 한국어를 받습니다. 목소리 고르기 화면에서 남성 목소리도 받아 두세요.
  3. 이 화면으로 돌아와 "목록 새로고침" → 아래에서 단계별 목소리를 고르고 🔊 미리 듣기.

위 목록은 태블릿 음성(Web Speech)일 때 쓰입니다. 강도 설정에서 Google·Azure 를 고르면 그 목소리로 읽고(시트 스크립트에 키 필요), 이 장소 이야기를 미리 만들어 태블릿에 저장할 수 있습니다.

조 번호 초기화 (리허설 뒤)

리허설이 끝나고 실제 행사 전에, 이 태블릿의 조 번호·방문 기록을 지워 1조부터 다시 시작합니다. 사진함은 그대로입니다. 모든 태블릿에서 누르고, 구글 시트의 "출발"·"기록" 탭 내용(첫 줄 제목 빼고)도 지워 주세요.
